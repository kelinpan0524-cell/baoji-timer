# 对抗性审查报告 — 多计划编排 / AI 计划 / 易用性防呆 / 性能（v1.2）

日期：2026-09-23 · 审查方式：5 个并行专项 agent（计划编辑、AI 能力、易用性防呆、性能增量、视觉终审）+ 实机截图复核
对象：commit 8ee992f 之后的多计划/编辑器/自然语言生成等新增能力

## 一、总体结论

新增功能的骨架正确（会话快照隔离、复制保留渐进规则、swap 事务、切换器现查数据、预览审批闭环），但发现 **3 个 P0、约 20 个 P1**，集中在三条主线：

1. **AI 输出未经清洗直接入库/渲染**——弱模型输出 `weekday:0`、字符串数字、`sets:0` 会分别导致预览页 RangeError 卡死、TypeError 被假错误掩盖、训练完成判定被毒化。
2. **飞书日历同步语义错位**——同步对象用"正在查看的计划"而非"使用中的计划"；14 天窗口每星期只写 1 次；清空动作/切换计划/非激活计划编辑都会留下错误日程。
3. **训练记录环节防抖缺失**——"完成本组"手抖双击记两组、误开训练无放弃出口、撤销只在休息态可点。

视觉终审 4/6 通过；不通过两项：AI 预览截图取证缺失（本报告后补）、新建提示条遮挡底部按钮。
