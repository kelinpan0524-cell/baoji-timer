# UI 设计规范 v1

目标：健身房暗光环境、单手、瞟一眼、零打扰。

## 设计原则（按优先级）

1. 训练中：计时数字是屏幕上最大的元素，占比 ≥ 1/2 屏高
2. 操作集中在拇指区（屏下 1/3）；关键按钮高度 ≥ 88dp，宽度全屏
3. 无弹窗：训练中一切确认用"按钮状态变化 + 震动"表达
4. 从打开 App 到第一组记录 ≤ 3 次点击

## 主题

- 背景 `#0E1116`（近黑深蓝灰）；卡片 `#1A2028`
- 主色 `#4ADE80`（绿，完成/开始）；警示 `#F87171`（红，失败组/退出）；强调 `#60A5FA`（蓝，链接/选中）
- 正文 `#E5E7EB`；次要文字 `#9CA3AF`
- 计时数字：等宽数字（tabular figures），颜色随剩余时间变化：>20% 绿 → ≤20% 橙 → 结束红闪
- 字体：系统默认；所有数字使用 `FontFeature.tabularFigures()`

## 页面清单与布局

### 1. 首页（今日）
- 顶部：问候 + 本周训练进度点（周一至周日 7 个点，练过的点亮）
- 大卡片：今日状态
  - 未开始：「今天该练：推力日 A · 4 个动作」+【开始训练】大按钮
  - 进行中：「训练进行中 · 第 2 个动作」+【继续训练】大按钮
  - 休息日：「今天是休息日」+ 查看计划/主动加练
- 下方：上次训练小结（动作数、总容量、时长）

### 2. 训练页（核心，全屏）
两个状态：**动作态** / **休息态**

动作态（从上到下）：
- 动作名（大字）+ 第 x/y 组 · 目标 5-8 次 @ RIR 2
- 上次成绩一行小字：「上次：80kg × 8,8,7」
- 当前设定重量超大数字（中间偏上），下方 +/- 步长按钮一排 5 个（0.5/1.25/2.5/5/自定义）
- 次数选择：一排大按钮（目标区间 ±2 覆盖），点选即计入，无需键盘
- 底部全宽大按钮【完成本组】（88dp 高）
- 右上角：跳过动作 / 结束训练（小字，不放底部防误触）

休息态：
- 全屏超大倒计时（数字占屏 ≥1/2）
- 次动作信息一行：「下一组：80kg × 8」
- 底部三个按钮：【+30s】【跳过休息】【提前结束】
- 锁屏/切后台：通知栏显示剩余时间；结束时刻震动+铃声
- 屏幕常亮（wakelock）训练期间保持

### 3. 计划页
- 周视图：7 天列，每天显示动作列表（点开看组数次数）
- 顶部：【AI 导入计划】入口；当前计划名 + 切换
- 动作详情：组数、次数范围、休息时长、类型（复合/辅助）、渐进规则摘要

### 4. 历史页
- 月历视图：有训练的日期标记训练类型颜色点
- 点日期 → 当日训练明细（每组重量×次数×RIR）

### 5. 数据页
- Tab：概览 / 肌肉 / 身体
- 概览：周容量折线图、四大项 1RM 进阶曲线
- 肌肉：正/背面分区热力图（CustomPainter 分区色块，颜色深浅=周训练量占比）
- 身体：体重/腰围/体脂折线 + 手动录入
- 底部：【生成 AI 分析包】大按钮

### 6. 设置页
- 训练偏好：默认休息时长（复合/辅助）、单位 kg、震动开关
- AI 配置：Base URL / API Key / 模型名（密码框，本地存储）
- 飞书配置：连接状态、粘贴授权信息、日历开关、测试按钮
- 数据：导出 CSV / 导出 JSON / AI 分析包 / 清空数据（二次确认）
- 权限：逐项说明 + 跳转系统设置（通知/勿扰/使用情况访问/精确闹钟/电池优化）

### 7. 首次启动引导（3 屏）
1. 欢迎 + 一句话定位
2. 权限说明（每个权限干什么、不给会怎样、可跳过）
3. 选计划：用内置薄肌计划 / 粘贴文本 AI 拆解 / 手动建

## 折叠屏适配

- 断点：<600dp 单栏；600-840dp 单栏加宽（内容最大宽 560dp 居中）；>840dp 双栏
- 训练页双栏：左栏=信息（动作、上次成绩、历史），右栏=操作（重量、次数、完成按钮）
- 计划页双栏：左=周日列表，右=选中日详情
- 禁止：训练页在折叠切换时丢失计时状态（状态全部存在全局 SessionController，与 Widget 无关）

## 性能基线

- 冷启动 <1.5s：首页 build 不做重查询（DB 查询放 isolate/异步 + 骨架占位）
- 训练页 60fps：倒计时用单一 Ticker 驱动一处 setState，其余静态；避免整页 rebuild
- 列表（历史/计划）用 ListView.builder 懒加载
- 图片资源仅图标，无大图
